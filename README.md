**Autor:** Romeo Robles

## Objetivo principal

Desarrollar aplicaciones **móviles** aplicando tecnologías multiplataforma y nativas: desde el backend y las herramientas en **Node.js**, hasta apps construidas con **React Native**, **Flutter/Dart** y **Kotlin** para Android, siguiendo buenas prácticas de estructura, versionamiento y despliegue.

---

## Tecnologías de la materia

### Node.js
Entorno de ejecución de JavaScript fuera del navegador, basado en el motor V8. Se usa para crear APIs/backends que consumen las apps móviles y para correr las herramientas de desarrollo (npm, Metro, Expo CLI).

### React Native
Framework de Meta para crear apps móviles **multiplataforma** (Android e iOS) con JavaScript/TypeScript y React. Los componentes se traducen a componentes nativos reales; con **Expo** se simplifica la configuración y las pruebas en el celular.

### Kotlin
Lenguaje moderno, conciso y seguro frente a nulos, **oficial de Google para Android**. Corre sobre la JVM, es interoperable con Java y se usa junto a **Gradle** y **Jetpack Compose** para construir apps nativas.

### Flutter
SDK de Google para crear apps multiplataforma (móvil, web y escritorio) desde **un solo código base**. Dibuja su propia interfaz con widgets, lo que da un rendimiento cercano al nativo y **hot reload** para ver cambios al instante.

### Dart
Lenguaje de programación de Google en el que se escribe Flutter. Es orientado a objetos, de tipado fuerte con null safety, y compila tanto a código nativo (AOT) como en modo desarrollo (JIT) para el hot reload.

## Estructura del repositorio

Cada proyecto o práctica de la materia se guarda en su propia carpeta dentro de este repositorio. El archivo `.gitignore` de la raíz cubre las carpetas y subcarpetas de proyectos Node.js, React Native, Kotlin, Flutter y Dart.
